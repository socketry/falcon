# Title

Concurrency

# Subtitle

Multiple operations make progress by interleaving on shared execution resources.

---

Concurrency is about structuring multiple tasks that are in progress together. They need not execute at the same instant: one processor can interleave them whenever a task waits or yields.

Hyper-threading is not a pure single-resource example. It is simultaneous multithreading: two hardware threads share one core's execution resources and may execute instructions simultaneously. It combines resource sharing with limited parallelism.
