# Understanding Falcon

Presentation for **Understanding Falcon with Samuel Williams — Online Store Lunch & Learn**.

The deck explains why Falcon exists, how a request moves through the Async and
Protocol::HTTP stack, and how the runtime is deployed and operated in production.

It contains 64 slides paced for 35 minutes, followed by discussion. Detailed
speaker notes are included with every slide.


## Setup

```bash
$ bundle install
```

## Running

```bash
$ bundle exec presently
```

Then open <http://localhost:9292> in your browser.

Use the **arrow keys** (or swipe) to navigate between slides.

For presenter notes, visit <http://localhost:9292/presenter>
